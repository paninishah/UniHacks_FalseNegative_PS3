# User Flow Reiteration

## Authentication & Onboarding
- **Signup**: Name, Password, Username (check required), DOB, Email
- **Login**: Username/Email, Password
- **Onboarding**: Profile setup (PFP, Bio, Public/Private visibility)

## Core Features
1. **Newsroom (Feed)**
    - Text-based posts: Meme, Confession, Roast, Joke
    - Photos
    - **News Bites**: Headline-generated (dramatic) posts, "News bites" terminology
    - General feed of all posts/activities

2. **Groups**
    - Create New / Admin Controls
    - Add/Remove Members
    - **News Bites (in Group)**: Group-specific feed/updates
    - **Games**:
        - Most Likely To
        - Skribbl
        - Cupid (Matchmaking)
    - **Features**:
        - Group Analytics
        - Friendship DNA (Labels: Top Roaster, etc.)
        - Memory Heatmap
        - Wall (Role assignment)
        - AI Chatbot (Smart engagement, prompts after inactivity)
        - Random Question Prompts
    - **Vanish Mode**: Ephemeral messaging
    - Participant List

3. **Public Communities (PopVerse)**
    - Similar to Groups but Public ("News Bites" terminology)
    - **Games**: Most Likely To, Skribbl
    - Open membership

4. **Vault**
    - **Private**: Key-based access (give keys to followers)
        - Only key holders + owner can view
    - **Public**: Everyone can view
    - Content: Images/Posts from previous times

5. **Season Recap**
    - End-of-cycle summary (MVP feature)

## Profile & Settings
- **Own Profile**:
    - PFP, Bio
    - Public/Private toggle
    - Followers / Following lists
    - **Post CRUD**: Text/Image, Filter/Sort, Image Captions
- **Other User Profile**:
    - View PFP, Bio
    - Followers / Following
    - See Posts
    - See Private Posts (if key held)
